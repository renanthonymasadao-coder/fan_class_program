# Fan Class - Encapsulation Activity

## Overview
This project demonstrates Object-Oriented Programming (OOP) principles in Python using encapsulation.

The program includes:
- Private attributes
- Getter and Setter methods
- Constructors
- Constants
- Separate class and test files
- Dynamic colored terminal output

## Project Structure

```text
fan_class/
│
├── fan.py
├── test_fan.py
└── README.md
```

## How to Run

